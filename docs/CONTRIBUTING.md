# Contributing to DevToolkit

Thank you for your interest in improving DevToolkit!

## Conventional Commits

We follow the [Conventional Commits](https://www.conventionalcommits.org/) specification:

- `feat(...)`: A new utility module or capability
- `test(...)`: Adding or refactoring unit tests
- `refactor(...)`: Code restructuring without API changes
- `chore(...)`: Project configuration, CI workflows, or metadata
- `docs(...)`: Documentation enhancements and README updates

## Development Workflow

1. Fork and clone the repository:
   ```bash
   git clone https://github.com/ASHISH-7142023/test-repo.git
   ```
2. Run the test suite before committing:
   ```bash
   python -m unittest discover tests -v
   ```
3. Submit a Pull Request following the PR template.
