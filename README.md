# DevToolkit - General Purpose Utility Library

A lightweight, zero-dependency utility toolkit for daily software engineering tasks. Includes robust modules for text manipulation, date formatting, data validation, and mathematics.

## Modules Overview

- **`src/string_utils.py`**: Slugification, case conversion (camelCase, snake_case), string truncation, and data masking.
- **`src/date_utils.py`**: Human-readable relative time, ISO datetime formatting, and date interval calculations.
- **`src/validators.py`**: Email, URL, strong password, and payload schema validation.
- **`src/math_utils.py`**: Clamping, moving averages, standard deviation, and percentage calculations.
- **`cli.py`**: Unified command-line interface.
